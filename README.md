# Mythfall — PixelForge Studios

A browser-playable fantasy card battler prototype.

## Play
Open `index.html` in a modern browser or use VS Code Live Server. No build step or runtime dependencies are required.

## Included
- Three AI trial opponents with sequential unlocks and victory rewards.
- Turn-based combat with a three-slot creature grid for each side.
- Increasing energy, card summoning, creature clashes and direct hero attacks.
- Four card rarities, collection, consumable items and loot crates.
- Published prototype crate odds.
- Responsive interface and in-game rules.
- Browser-local save using localStorage.

## Assets
The game loads the existing card artwork from `Cards/`. If an image is missing, the interface falls back to the creature emoji. Exotic artwork is currently a placeholder until the asset is added.

## Rules
See [RULES.md](RULES.md).

## Limitations
Early single-player prototype. No online multiplayer, accounts, server-side progression, ranked mode or real-money transactions. AI, card effects and balance need continued playtesting.
